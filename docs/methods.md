# 核心方法与改进

本系统将当前状态估计、未来测验概率和路径安排分开建模。这样可以分别检查证据、模型与决策，避免把一个不透明分数当作所有问题的答案。

## 知识图谱和学习路径

知识关系包含 `PREREQUISITE`、`RELATED` 和 `PART_OF`。只有先修边构成硬顺序约束。方向为前置知识 → 后续知识。

路径计算步骤：

1. 从目标逆向收集全部先修祖先，形成先修闭包。
2. 在闭包内计算入度，用 Kahn 算法生成拓扑序。
3. 只有入度为零的节点可以进入候选集合，集合内部按难度升序、重要性降序及稳定 ID 排序。
4. 节点估计掌握度达到阈值且至少有 5 次计分证据时，才从待学步骤中跳过；默认阈值 0.8，可调整为 0.7 或 0.9。短时间反复做同题不会凑够门槛。
5. 估计时长为 `ceil(referenceMinutes × (1 − 0.55 × mastery))`，最少 5 分钟。
6. 根据预算取连续前缀，首个无法完整放入预算的步骤及其后的步骤都留待后续学习。

算法不保证全局最短路径。对拥有多个硬先修条件的目标，需要覆盖全部必要祖先，而不是挑选一条图上的最短路线。保留就绪集合约束也比对最终 DFS 序列随意按难度重排更可靠。

新增先修关系时，对目标到源的可达性进行检查。知识节点行在事务中被锁定，让并发写入串行检查，避免两条各自检查合法的新增边组合成环。读取到已有环时返回 422，不伪造回退路径。

## 当前掌握度估计

使用可解释的贝叶斯知识追踪作为基线。初始潜在掌握概率 `P(L₀)=0.15`，猜对率 `P(G)=0.20`，失误率 `P(S)=0.08+0.009×difficulty`，学习转移率 `P(T)=0.06`。

答对时：

```text
posterior = p × (1 − slip) / [p × (1 − slip) + (1 − p) × guess]
p_next = posterior + (1 − posterior) × learn
```

答错时：

```text
posterior = p × slip / [p × slip + (1 − p) × (1 − guess)]
p_next = posterior + (1 − posterior) × learn
```

每个实际题目生成一个事件，按时间及事件 ID 稳定排序后更新。同一道题距上次计分不足 24 小时的重做仍保留为练习，但不参与 BKT 更新、证据正确率、Wilson 区间和路径跳过门槛；重复练习也不会延长这段冷却时间。24 小时是工程防重复规则，不是经实验证明的最佳复测间隔。

`attempts/correct` 表示全部练习，`evidenceAttempts/evidenceCorrect` 表示参与估计的计分证据。历史数据没有题号时无法可靠追溯，保持原有计分并在 `legacyAttempts` 和证据提示中明确标记；不会猜测历史题号。新增关联表记录新作答的题号，旧数据库可直接启动，不清空学习记录。

仅保存学习时间不会当作掌握证据，也不会重置距最近计分诊断的天数。相邻计分作答之间和最后一次计分之后均应用遗忘参考机制：

```text
halfLifeDays = 20 + 2 × min(evidenceAttempts, 30)
retained = 0.15 + (p − 0.15) × 0.5^(elapsedDays / halfLifeDays)
```

这些参数是演示先验，不是对真实学习者估计或验证的认知参数。遗忘机制会将估计向先验回归，也可能让低于先验的值回升；这是不确定性回归，不应解释成无学习自动进步。

页面另外展示计分证据答对比例的 95% Wilson 区间。它不是潜在掌握度置信区间；24 小时去重仍无法消除题目记忆、作答依赖及难度不均衡。证据等级按计分次数划分，只用于提示记录量，不能声称这些记录在统计上独立。

## 未来答对概率与训练

训练目标是下一次作答的二元正确性。输入包括前次掌握度估计、历史正确率、历史作答次数、累计学习时间、难度、最近间隔、前置知识估计、计划学习时间和预测间隔。

`train.py` 逐步模拟 120 位学习者、18 个知识点和每个知识点 8 次作答。所有历史特征在该次答案出现前生成，再采样该次正确性标签；这一答案只能影响后续样本。

训练、校准和独立测试分别使用 72、24、24 位不同学习者。训练组仅使用前 6 次作答，后 2 次形成另外的时间向后验证集。训练 7,776 条、校准 3,456 条、独立测试 3,456 条、时间验证 2,592 条。固定随机种子为 2026。

随机森林、梯度提升和极端随机树的概率平均形成集成输出。对独立校准组的集成概率 logit 使用逻辑回归校准；校准组不参与基模型训练，测试组不参与训练或校准。逻辑回归独立模型作为比较基线。

展示 AUC、Brier、二元标签上的 RMSE、对数损失、准确率和 10 桶 ECE。准确率使用 0.5 判定阈值。页面保留每个基模型和基线，不能把“集成”直接视为更准确。

输入超过训练中的常见范围时，返回分布外提示。只展示各基模型概率，明确其不是统计区间。全局特征重要性写入指标报告，它不是对当前个体预测的因果解释。

情景对比使用一次批量请求，保持学习者特征和测验间隔相同，分别设置额外学习时间为用户输入与 0 分钟。返回两种答对概率及其差值，负差如实保留，差值不是学习投入的因果收益；0 分钟时两种结果相同。界面修改参数后会标注旧结果，重新计算后更新。

在线预测的历史正确率和次数使用计分证据，避免短时间重复练习直接堆高输入。训练模拟中的每个步骤仍视为新证据；本轮没有新增真实数据、重训或宣称预测精度提升，现有指标对应原合成训练与评估数据。

## 容错与实现边界

Java 调用 Python 的连接超时为 800 ms，请求超时为 1,800 ms。模型服务失败或成对响应不完整时，情景和基准统一返回 `rule-fallback`，避免混合模型与规则的数字进行比较。保留输入摘要，并明确规则未经真实数据校准。回退输出不会写回当前掌握度。

规则使用遗忘参考、难度和计划时间计算学习增益，再换算为猜对与失误下的正确性概率。这属于启发式演示，不是训练模型的等价替代。

预测服务支持最多 100 个输入的向量化批量接口，每批对各基模型和校准器各调用一次；单条接口复用同一推理路径，测试检查逐项结果一致。没有据此声称具体倍数的性能提升。模型加载后驻留进程内；重新训练后需要重启服务，避免静默更换模型版本。

尚未实现真实数据训练入口、模型在线增量训练、深度知识追踪、强化学习、自然语言知识抽取或跨课程泛化。当前课程和 3 题诊断也不构成完整自适应测验系统。

## 安全与数据约束

服务端验证会话、角色和数据归属。会话令牌是 32 字节随机值，以 SHA-256 摘要存储，Cookie 使用 HttpOnly 和 SameSite=Strict；写接口使用会话绑定的随机 CSRF 令牌，并检查有来源头的请求。生产 HTTPS 可启用 Secure。

密码使用 BCrypt，注册只能创建学习者角色；登录失败使用进程内短期限流。教师与管理员才能编辑共享知识库。学习记录和测验归属来自服务端会话，不采纳客户端传来的用户 ID。测验结果以事务和行锁完成，重复提交返回已存结果。

这些措施是本项目实际实施的范围。系统没有外部安全审计、分布式限流、账号找回、生产级灾备或长期运维验证。
