# 作品集展示讲解

## 约三分钟的演示流程

**0:00–0:30 说明问题。** 在线学习中，知识点并不独立。只有看课程完成比例，很难判断“应该下一步学什么”。本项目把知识依赖、测验证据和路径规划连接起来。

**0:30–1:00 展示图谱。** 进入学习者演示，打开知识图谱，选择 Dijkstra。指出它依赖广度搜索和优先队列，并展示缩放和节点详情。解释实线先修关系会约束路径，关联与组成关系只帮助理解结构。

**1:00–1:30 展示路径。** 以 Dijkstra 为目标，设置 90 分钟预算。演示完整路线与本次安排的区别。说明只在可学节点里按难度排序，预算不足时不跨过必学先修内容。

**1:30–2:00 展示反馈。** 选择拓扑排序完成诊断。查看判分、解析和新增计分量，立即重做可看到“仅记练习”，掌握度不会因刷同题继续增长。说明 24 小时规则与阅读时长不计掌握的边界。

**2:00–2:40 展示预测与评估。** 对比额外学习 30 分钟与 0 分钟基准，把时间改成 0 后两者相等。说明差值不是因果效果。打开模型评估，展示隔离的学习者集合、时间向后验证与逻辑回归基线，指出合成指标不代表真实教学效果。

**2:40–3:00 展示可靠性。** 使用教师演示尝试添加 Dijkstra → 算法复杂度的先修边，展示循环拒绝。结束时说明自动测试覆盖权限、测验幂等、随机 DAG 顺序和预测故障回退。

## 可使用的项目描述

依据毕业论文独立复现在线学习知识分析预测系统，使用 React、Spring Boot 和 Python 构建知识图谱、掌握度分析、个性化路径与测验反馈闭环。将 DFS 路径重排改为受先修约束的拓扑排序，增加预算前缀规划、循环关系校验和服务端数据隔离。实现 BKT 状态更新与经校准的集成答对概率预测，用学习者隔离和时间向后切分评估模型，并保留基线与指标局限。

这段描述对应当前已实现功能，不包含原论文的准确率、并发能力或尚未实现的深度学习与在线训练。
