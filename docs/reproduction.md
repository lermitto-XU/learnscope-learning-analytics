# 论文核心方案与实现对应

来源为许圣昊 2025 年毕业论文《在线学习服务中知识分析预测系统设计与实现》。未提供原始源码、原训练集、完整接口或数据库建表脚本；本项目依据正文描述独立实现，不将推断内容称为原程序。

| 论文内容 | 实现位置 | 处理方式 |
| --- | --- | --- |
| 3.1 前后端与 Python 预测分层 | `web/`、`server/`、`predictor/` | 保留 React、Spring Boot、Python 的服务边界，更新工具版本 |
| 4.1 知识点与三类关系 | `Store.java`、`seed.json`、`Graph.tsx` | 关系型存储、交互图谱、角色约束的知识维护；采用项目自写课程 |
| 4.2 动态路径与掌握度过滤 | `PathService.java`、`Path.tsx` | 改为先修闭包与拓扑排序；预算内只保留可行前缀 |
| 4.3 多行为特征与集成预测 | `MasteryService.java`、`PredictionService.java`、`train.py` | 区分 BKT 状态估计与下一次答对概率；独立校准与真实指标展示 |
| 4.4 图表与知识网络 | `chart-engine.ts`、`Graph.tsx`、`Analysis.tsx` | 按需加载 ECharts；SVG 图谱支持节点拖动、画布平移与缩放 |
| 4.5 认证与权限 | `AuthService.java`、`WebConfig.java` | 以服务端会话、HttpOnly Cookie 和 CSRF 替代本地存储令牌 |
| 4.6 仪表盘与推荐 | `LearningService.java`、`Dashboard.tsx` | 实时统计、先修满足的候选知识推荐；不加入独立目标管理模块 |
| 4.7 测验与反馈 | `LearningService.java`、`Assessment.tsx` | 服务端判分、结构化解析、归属校验与幂等提交；演示仅单选题 |
| 4.11 知识对比 | `Analysis.tsx` | 最多 5 个知识点的归一化雷达比较；不宣称推导真实认知难度 |
| 4.13 知识维护 | `ApiController.java`、`Manage.tsx` | 创建和编辑节点、增删关系、版本检查、审计事件；没有分布式监控平台 |
| 5–6 优化、训练与验证 | 懒加载、超时回退、Java/Python/浏览器测试 | 重新验证本实现，不复用论文报告的性能结论 |

遵循项目范围调整，省略笔记、计划、成就、积分、独立资源库、头像及个人资料功能。学习详情包含自写课程正文，支撑核心闭环。

知识维护当前提供节点创建和内容元数据编辑，没有节点删除或完整课程导入。新增节点不自动创建题目，未配置题库时测验返回 422。该边界已在管理页明确说明。

论文正文有若干宽泛技术描述，例如深度学习、强化学习、在线增量训练、自动索引及水平扩容。本项目不把这些描述当作已可复现的算法细节，也不将没有实测的能力写入作品集。
